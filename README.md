# Game2

A small dungeon-crawler experiment focused on a coherent world and a highly polished, limited playable scope.

The immediate focus is the hub. Character work comes next, with no weapons. The hub will build on the original crawler's visual style, with improvements and additions guided by the purpose of each place and object.

This repository currently contains planning notes only. No playable build or assets have been added yet.

- [Story premise and hidden lore](docs/STORY.md)
- [Current scope and reuse policy](docs/SCOPE.md)

The original crawler remains a separate local reference. Only files actually reused in this game will be brought into this repository.
