# Before the First Gate

80-second cinematic using the approved script and one continuous ElevenLabs performance of the selected lighter herald voice. No separate character voices or per-passage pitch shifts. The original voice identity is retained; punctuation and delivery supply expression.

Five illustrated scenes: village, war, sacrifice, decree, and children at home. The gate scene begins with the spoken decree. The closing image is unique.

Animated elements: edge-first ink reveal, slow camera movement, chimney smoke, river ripples, banner movement, dissolving-cloak drift, candlelight, portal light, sparse drifting particles and subtle blanket breathing. These are local shader animations over generated illustrations, not fully rigged character animation.

Subtitles follow the API character timestamps. The standalone version closes on completion or Escape. The Game2 version plays on New Game, pauses the hub while active, and restores the hub on completion or Skip. Continue bypasses the cinematic.

The script is in SCRIPT.md. Play the video or run play.fish for the live Godot version. Source illustration prompts are in art-prompts.json; artwork used the built-in imagegen tool. No API credentials are included.
